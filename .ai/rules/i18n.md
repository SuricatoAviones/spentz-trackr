# I18N

## i18n dictionary consistency enforced by I18nDictionaryTest
Keep es.json and en.json key-identical. `tests/Unit/I18nDictionaryTest.php` enforces: (1) identical flat key sets, (2) every static `t('...')` key in resources/js resolves in the dictionaries (plural variants `_one/_other` etc. count as valid), (3) `:placeholder` interpolation sets match between languages. Run it after adding or renaming any key.
